## Context
当前打印依赖 window.print，页面高度固定。已有未提交的工作区与 AI 功能应保留，不纳入本次提交。

## Goals / Non-Goals
目标：不裁切、每页留白、资源就绪后打印、可解释的一页适配。
本轮不引入服务端渲染或宣称 ATS 兼容；精确分页预览通过浏览器打印预览提供，屏幕为连续内容预览。

## Decisions
采用 CSS 分页保留原生文本和链接。@page 负责重复边距，正文取消固定高度。保持现有 flex order 栏目顺序。资源等待封装到独立模块，设超时、失败不打印、阻止重复请求。一页适配先减栏目间距，后调整字体与行距，达到下限建议多页。

## Risks / Trade-offs
浏览器设置可能改变分页；界面明确最终页数以打印预览为准。浏览器无法可靠告知用户保存成功，状态只能描述打开打印预览。

## Migration Plan
无需数据迁移；移除裁切样式即可回退布局策略。
