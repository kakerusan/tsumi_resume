## Context
沿用单栏结构、主题变量和现有 CSS 排版，不新增主题选择或数据迁移。
## Goals / Non-Goals
提升扫读、重点识别和打印效果；不自动改写、加粗或删减用户内容。
## Decisions
使用细分隔线和深色栏目标题减少装饰竞争；经历头部轻底色及左侧标记；用户显式 strong 采用深色强调；主题色标签保留低饱和背景和边界。项目链接显示“项目链接”而不假定一定是 GitHub。长名称允许自然换行，日期使用等宽数字。保留所有字号与行距变量。
## Risks / Trade-offs
视觉改动可能影响分页，使用实际 PDF 逐页检查并确认文本完整性。主题色可能极浅，正文与强调保持深色可读。
